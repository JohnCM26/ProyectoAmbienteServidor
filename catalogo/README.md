# Módulo de Catálogo y Búsqueda

Responsable: Jenner Villarreal.

## Funcionalidades

- Mostrar el catálogo de libros y materiales disponibles.
- Implementar la búsqueda de libros por título.
- Agregar filtros por categoría y otros criterios.
- Mostrar los resultados de las búsquedas.

## Archivos previstos

1. catalogo.html - Interfaz del catálogo con buscador y filtros por categoría y condición.
2. buscador.php - Script de procesamiento en PHP que realiza el filtrado de datos y visualización de resultados.
