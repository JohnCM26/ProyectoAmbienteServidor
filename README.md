# Proyecto Ambiente Servidor Web

## Descripción del proyecto

Desarrollo de una plataforma web para la publicación, búsqueda y consulta de libros y materiales.

El proyecto se desarrolla en equipo utilizando HTML5 y otras tecnologías que se incorporarán según las necesidades del sistema.

## Objetivo general

Desarrollar una plataforma web que permita a los usuarios registrarse, iniciar sesión, publicar libros y materiales, consultar publicaciones y realizar búsquedas mediante diferentes criterios.

## Tecnologías utilizadas

- **HTML5:** estructura de las páginas web.
- **CSS3:** diseño y estilos visuales.
- **JavaScript:** interactividad y funcionalidades del lado del cliente.
- **PHP:** procesamiento y lógica del lado del servidor.
- **Git:** control de versiones del proyecto.
- **GitHub:** almacenamiento del código y colaboración entre integrantes.

## Control de versiones

El proyecto utiliza GitHub para gestionar el código fuente, registrar los cambios realizados por cada integrante y facilitar la integración de los diferentes módulos.

Cada integrante será responsable de registrar sus aportes mediante commits.
